Matrix Access Management

Manage Matrix users, approved rooms, and the MCP allowlist for assistant-level users.

How Matrix usage works

  • admin_usage: full direct-message and group-room access, including slash commands.
  • assistant_usage: no direct-message usage; allowed only in approved rooms and only with checked MCPs.
  • no_assistant_usage: fully ignored everywhere, including approved rooms.
  • Approved rooms are activated when an admin invites the bot there.
  • In group rooms the bot answers only when mentioned or replied to.

Telegram Group Access

Manage approved groups and the MCP allowlist for non-owner users in those groups.

How Telegram group access works

  • The bot ignores all non-owners in private chats.
  • In groups, the bot only responds when directly mentioned (@botname) or replied to.
  • Use /approve@botname in a group to allow non-owners there to interact.
  • Use /unapprove@botname to remove a group's access.
  • Non-owners in approved groups can only call the MCPs checked below.
